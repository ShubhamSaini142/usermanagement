## ✨ Features

- 📋 **List users** fetched from a REST API
- ➕ **Add a user** with a form (`/add`)
- ✏️ **Edit a user** (`/edit/:id`)
- 🗑️ **Delete a user** from the list
- 🧭 **Client-side routing** with React Router

> Data comes from the [JSONPlaceholder](https://jsonplaceholder.typicode.com/) mock API, so create, update and delete requests are simulated and not saved.

## 🚀 Getting Started

```bash
npm install
npm start          # opens http://localhost:3000
```
